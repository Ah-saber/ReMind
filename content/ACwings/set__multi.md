- ### 基本用法
	- 都是无序（排序好的）
	- multi的区别
		- 可以重复
	- ```c++
	  [[include]]<set>
	  
	  size();
	  empty();
	  clear();
	  insert();
	  find();  //查找一个数，找到就返回迭代器
	  count();  //计数，返回一个数的个数
	  //删除
	  erase(); //输入一个数就删除该数，输入迭代器就删掉迭代器
	  //在multiset中，用迭代器可以只删一个，用数会删掉全部(k + log n)
	  lower_bound()/upper_bound();   
	  //返回大于等于x的最小值（迭代器）  与  返回大于x的最小值（迭代器）
	  //可用于二分
	  
	  begin();/ end();  // 使用  --   ++    返回前驱（钱一个迭代器）和后继（后一个迭代器）
	  ```
