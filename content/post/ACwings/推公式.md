题意：牛危险系数定义为：上面的牛的重量和减去自身的强壮度，牛与牛叠罗汉，问怎么叠最大的风险值最小

# 思路

列公式推

![[推公式 2024-03-22 00.20.47.excalidraw]]
即按w+s从小到大排序，从上到下叠

## 实现

```C++
#include <iostream>
#include <algorithm>


using namespace std;

const int N = 5e4 + 10;

typedef long long LL;
typedef pair<LL, LL> PII;

PII cow[N];

int main()
{
    int n;
    cin >> n;
    
    for(int i =  0 ; i < n; i ++)
    {
        int w, s;
        cin >> w >> s;
        cow[i].first = w+s;
        cow[i].second = w;
    }
    
    sort(cow, cow + n);
    
    LL ans = -2e9;
    LL W = 0;
    for(int i = 0; i < n; i ++)
    {
        int w = cow[i].second;
        //int s = cow[i].first - w;
        W += w;
        
        ans = max(ans, W - cow[i].first);
    }
    
    cout << ans << endl;
    
    return 0;
}
```
