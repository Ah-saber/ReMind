# 题意

给定饮料的名称和等级，之后给出由两种饮料名称组合的字符串，要求按照一开始给定的饮料等级对该字符串进行划分
> Coke A
> Diet D
> DietCoke
> DA

 如果有多种拆分或无法拆分，等级为D


# 题解

注意看题

仅由两种饮料组合而成，且每个字符串长度不超过30

用map哈希每种饮料，直接遍历第一种饮料的字符串，将字符划分为两个字符，对每每两个字符进行查找，都找得到说明存在，给出答案，找到多种或找不到答案更新为D

```C++
#include <bits/stdc++.h>

using namespace std;


map<string, string> mp;

void solve(string s)
{
    int len = s.length();

    int cnt = 0;
    string ans = "D";
    for(int i = 0; i < len; i ++)
    {
        string s1 = s.substr(0, i), s2 = s.substr(i, len);

        //只能分成两个
        if(mp.count(s1) && mp.count(s2))
        {
            cnt ++;
            ans = mp[s1] + mp[s2];
        }

        if(cnt > 1)
        {
            ans = "D";
            break;
        }
    }

    cout << ans << endl;    
}

int main()
{
    int n, m;
    cin >> n >> m;

    for(int i = 0; i < n; i ++)
    {
        string a, b;
        cin >> a >> b;
        mp[a] = b;
    }

    for(int i = 0; i < m; i ++)
    {
        string s;
        cin >> s;
        if(mp.count(s))
        {
            cout << mp[s] << endl;
        }
        else solve(s);
    }

    return 0;
}
```

题完全不难，关键在看题和实现
