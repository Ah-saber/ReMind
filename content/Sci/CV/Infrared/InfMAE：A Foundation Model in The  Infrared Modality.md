# Key Issue

说当前缺乏一个应用于红外的backbone

同时，自监督模型中传统的掩码策略不适用于红外的弱纹理，弱细节图像，不利于恢复甚至重建图像细节

# Motivation

用动态的掩码策略来代替传统的掩码策略，保证不会过多的掩盖关键细节

# Method

在强度特征图上分析，通过一个卷积后计算强度均值，得到灰度图，将灰度图转换成token（16个patch），降序排序后赋予ID，再间隔S来取出可见的token

![[Pasted image 20251025092634.png]]

这样一来不同强度、特征结果，取出的ID不同，再加上后续的多尺度方法，尽可能的提取细节

# Conclusion

实际上不觉得很有创新，没有真正针对到红外的特性，动态的随机掩码没有任何能得到细节的依据，从直观上看似乎可以，但依旧是多种小创新堆叠出来的结果提升
